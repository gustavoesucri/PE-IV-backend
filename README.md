# PE-IV - Como Executar

## Backend

```bash
cd PE-IV-backend
npm install
npm run seed:full        # popula o banco com dados básicos
npm run start       # inicia o servidor
```

## Frontend

```bash
cd PE-IV-frontend
npm install
npm run start       # inicia o cliente
```
